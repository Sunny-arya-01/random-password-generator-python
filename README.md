# random-password-generator-python
A simple Python project that generates random, secure passwords using uppercase letters, lowercase letters, digits, and special characters.

Random Password Generator (Python)

A beginner-friendly Python project that generates random passwords using uppercase letters, lowercase letters, numbers, and special characters.

Features

- Generates passwords of a user-defined length.
- Includes uppercase and lowercase letters.
- Includes numbers and special characters.
- Ensures at least one character from each of these four categories.
- Shuffles the generated password for a random arrangement.
- Validates the minimum password length.

Technologies Used

- Python 3
- "random" module
- "string" module

How to Run

1. Install Python 3 if it is not already installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

python password_generator.py

5. Enter the desired password length when prompted.

Example

Enter password Length : 12
Your random Password is :  aB7@kL2#pQ9!

The password shown above is only an example.

This project helped me practise Python input handling, conditional statements, loops, lists, string manipulation, random selection, and basic password generation.
